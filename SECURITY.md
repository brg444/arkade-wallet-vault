# Security policy

Arkade Vault Wallet is under active security review, with no public bug-bounty
program. The current release candidate is restricted to Mutinynet, and
real-fund use remains out of scope.

Report suspected unauthorized spending, Vault Program substitution, enrollment
or tenant-isolation failures, transaction-verification defects, recovery
bypasses, and private-key exposure through a
[private GitHub security advisory][advisory]. Include the affected commit,
browser and deployment assumptions, reproduction steps, and potential fund
impact. Keep exploits and sensitive user data out of public issues.

The maintainers will acknowledge the report, reproduce it against the current
release candidate, and coordinate remediation and disclosure. General defects
without a security impact may use the public issue tracker.

[advisory]: https://github.com/brg444/arkade-wallet-vault/security/advisories/new
