# Security

Mutinynet demo. Not a bounty program.

If you think you can spend someone else’s vault, skip the invite, or
make the service sign an address it did not build itself, report it
privately: open a [security advisory][advisory] on this repo. Include
enough to reproduce. Do not open a public issue with a live exploit.

[advisory]: https://github.com/brg444/arkade-wallet-vault/security/advisories/new
